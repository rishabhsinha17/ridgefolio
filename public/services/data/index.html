Data systems & reporting

Give staff a map or dashboard backed by a reporting pipeline they can check against source records.

Where to start

When monthly totals differ between reports, staff need a way to trace the difference. Build the reconciliation step into the reporting process so staff can tell which records changed.

Open the interactive demo ↗

What the work includes

Source inventory
Document the owner, format, refresh interval and allowed use of each source. Agree on a definition for each measure.
Data preparation
Validate incoming records, isolate exceptions and keep stable identifiers across refreshes.
Maps and reporting
Design filters around decisions, include documented calculations and export the selected records. For an AI-assisted task, test its answers against a labeled sample before release.

How to evaluate it

Filter a known sample, compare the count and sum to an independent calculation, then export the records and reproduce both numbers.

What affects scope

Source quality, update frequency, geographic coverage, access rules and the number of reporting views drive effort.
